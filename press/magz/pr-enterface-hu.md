# ENTERFACE

<div style="text-align:center;">
<img src="enterface-hu/logo-eface.png" alt=""></div>

«Enter-Face» мав стати щомісячним журналом для користувачів Enterprise, але, на жаль, вийшов лише один його випуск. Причиною цього, ймовірно, була повна відсутність реклами, через що більшість користувачів навіть не знали про вихід журналу. До речі, єдиний номер видала студія «['á'-Studió](../../companies/a-studio.md)».
