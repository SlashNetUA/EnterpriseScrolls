# LPT (Line Parameters Table)



На відміну від більшості тогочасних відеочипів (як-от у ZX Spectrum чи C64), які автоматично та невидимо для програміста керували кадровим гасінням (VBlank) та кадровим синхроімпульсом, Nick цього сам не робить. Програміст має власноруч додати в кінець таблиці LPT спеціальні «пусті» блоки параметрів (LPB), які не виводять графіку, а натомість апаратно виставляють біти вертикального синхроімпульсу (Vertical Sync) та гасіння, щоб телевізор чи монітор зрозумів, де закінчується один кадр і починається наступний.

## EXOS LPT

EXOS використовує власну "спрощену" таблицю LPT у фіксованому місці в абсолютній області RAM пристрою. Таблиця параметрів рядків завжди складається з 28 блоків параметрів рядків (по 9 сканлайнів кожен) для ділянки відображення, а також кількох інших блоків для генерації кадрової синхронізації та рамки.

Перший блок параметрів рядків зарезервований для відображення рядка стану, який є фіксованою областю в RAM. Інші 27 блоків параметрів рядків можуть відображати будь-яку частину будь-якої сторінки, тому відображення завжди здійснюється вертикальними блоками по 9 пікселів.

Усі 28 блоків параметрів рядків початково налаштовані як порожні (тобто мають колір бордюру). Змінна [LP_POINTER](../exos-variables/sys-var_lp-pointer.md) в області змінних EXOS вказує на початок таблиці параметрів рядків.
