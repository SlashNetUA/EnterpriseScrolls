# Порт 183 / B7h

Ніжки **WR2** та **RD2** чіпа [Dave](../../../hardware/hm-dave.md)

## Запис

| біт | опис                                                                                               |
|:---:| -------------------------------------------------------------------------------------------------- |
|  0  | вихід даних (DATA OUT) [роз'єму Serial/Net](../../../hardware/connections/pinouts-serial-net.md)   |
|  1  | вихід стану (STATUS OUT) [роз'єму Serial/Net](../../../hardware/connections/pinouts-serial-net.md) |
| 2-7 | не використовуються                                                                                |

> **ZozoSoft**:  
> Запис у B7h (WR2): зберігаються лише 2 біти в тригері, реалізованому на мікросхемі **74LS74** (U30). біт 0: вихід даних (DATA OUT) роз'єму Serial/Net біт 1: вихід стану (STATUS OUT) роз'єму Serial/Net

## Зчитування

Зчитування з B7h (RD2): не використовується.
