# USR_P0, USR_P1, USR_P2, USR_P3

Адреси пам'яті: 

**0BFFFh** - **USR_P3**  
**0BFFEh** - **USR_P2**  
**0BFFDh** - **USR_P1**  
**0BFFCh** - **USR_P0**

These are the four segments which were paged in when [EXOS](../../../software/ss-exos.md) was last called. Undefined when not in EXOS.
