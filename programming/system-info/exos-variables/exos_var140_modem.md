# 140 - DTMFDUR — Duration and spacing of dial-tones.

Пристрої: [MODEM](../exos-devices/modem.md)  

`ASK 140 var`  
`SET 140, expr`  
`TOGGLE 140` - inverts value.

When using dial-tones, the value indicates the duration of, and spacing between the tones. Value is in 1/1200 sec. units, with a default of 140 ms.

When using pulse-dialing, the value indicates the time between the dial-pulses in units of 1/150 sec.
