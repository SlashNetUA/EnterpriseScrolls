# 145 - DBASX.EXT

`ASK 145 var`  
`SET 145, expr`  
`TOGGLE 145` - inverts value;  
 
Програма DBASX.EXT, залежно від стану системної змінної 145, «обманює» [BASIC](../../is-basic.md), повідомляючи, що більше немає розширень BASIC. Це перешкоджає тому, щоб [BRD](../../../software/ss-localizations.md) або [PLUS](../../../hardware/cartridge/enterprise-plus.md) розміщували свої процедури розширення, завдяки чому такі вибагливі програми, що працюють лише на англійському BASIC, успішно запускаються. Після зміни значення цієї змінної потрібно виконати команду `:BASIC`, оскільки опитування розширень відбувається саме під час входу в BASIC.

**0**: розширення Бейсика дозволені.   
**255** (**≠0**): (**за замовчуванням**) розширення Бейсика відключені.
