# 36 - REM1

Пристрій: [TAPE](../exos-devices/tape.md)  

`ASK 36 var`  
`SET 36, expr`  
`TOGGLE 36` - inverts value.

State of cassette remote controls.

**≠0**: (default) off (hold)  
**0**: on (release)

# 37 - REM2

Пристрій: [TAPE](../exos-devices/tape.md)

`TOGGLE 37` - inverts value.

State of cassette remote controls.

**≠0**: (default) off (hold)  
**0**: on (release)
