# 15 - BUF_SND

Пристрій: [SOUND](../exos-devices/sound.md)

`ASK 15 var`  
`SET 15, expr`  
`TOGGLE 15` - inverts value.

Sound envelope storage size in *phases*. Possible values are **1**-**255**

**20**: Default
