# 33 - SP_TAPE

Пристрій: [TAPE](../exos-devices/tape.md)  

`ASK 33 var`  
`SET 33, expr`  
`TOGGLE 33` - inverts value.

Saving speed for tape operations.

**0**: (default) high - 2400 baud  
**≠0**: low - 1200 baud
