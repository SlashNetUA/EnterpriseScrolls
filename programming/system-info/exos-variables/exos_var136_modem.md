# 136 - MOD_DISPLAY — Modem status display

Пристрої: [MODEM](../exos-devices/modem.md)  

`ASK 136 var`  
`SET 136, expr`  
`TOGGLE 136` - inverts value.

This variable enables/disables the display of the modem status in the status line.

 - **0**: display ON (default)
 - **≠0**: display OFF
