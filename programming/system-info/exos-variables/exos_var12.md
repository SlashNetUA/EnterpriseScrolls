# 12 - TAPE_SND

Пристрій: [SOUND](../exos-devices/sound.md)

`ASK 12 var`  
`SET 12, expr`  
`TOGGLE 12` - inverts value

**0** : Tape sound feedthrough enabled (default).  
**255** (**≠0**): Feedthrough disabled.
