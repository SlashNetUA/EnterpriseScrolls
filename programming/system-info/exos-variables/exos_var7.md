# 7 - CLICK_KEY

Пристрій: [KEYBOARD](../exos-devices/keyboard.md)  

`ASK 7 var`  
`SET 7, expr`  
`TOGGLE 7` - inverts value.

**0**: Key click enabled (default).  
**255** (**≠0**): Key click disabled.
