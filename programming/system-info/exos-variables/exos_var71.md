# 71 - DEF_UNIT

Current drive number

**not exist[^1]**: non EXDOS configuration, ep128emu [FILEIO](../exos-devices/fileio.md) device used.  
**1**-**4**: Floppy disk.  
**5**: RAMDISK.  
**≥6**: SD/HDD.  

[^1]: **not exist** cause error [#9242](../errors/9k/err-9242.md) (Unknown EXOS variable number)
