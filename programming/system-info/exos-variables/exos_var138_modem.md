# 138 - DIALMAX — Max. wait for dial tone

Пристрої: [MODEM](../exos-devices/modem.md)  

`ASK 138 var`  
`SET 138, expr`  
`TOGGLE 138` - inverts value.

Default: 20 sec.

This is the maximum wait time for detection of the call-progress tone (ready-tone). Value is in 1/10 sec. units.
