# 141 - RINGNUM — No. of rings on which modem answers

Пристрої: [MODEM](../exos-devices/modem.md)  

`ASK 141 var`  
`SET 141, expr`  
`TOGGLE 141` - inverts value.

Default value: **2**

This selects the no. of rings on which the modem should answer a call. (if autoanswering is enabeled).
