# PRINTER:

`PRINTER:`

Драйвер принтера — це дуже простий пристрій, який просто надсилає символи на принтер (або інший пристрій), використовуючи вбудований паралельний інтерфейс типу Centronics.

Одночасно до драйвера принтера може бути відкрито лише один канал; якщо буде зроблено спробу відкрити другий канал, буде повернено помилку [.2NDCH](../errors/err-2ndch.md). Канал можна відкрити, вказавши назву пристрою `PRINTER:`, при цьому будь-яке ім'я файла чи номер пристрою ігноруються.

Після відкриття каналу символи можна записувати за допомогою виклику функції посимвольного запису або блокового запису. Символи надсилатимуться без будь-якої інтерпретації, і передаються всі 8 біт.

Технічні специфікації драйверу послідовного порта:

- EXOS version 1 (missing)
- [EXOS version 2.0](http://enterprise.iko.hu/technical/ET16-2_EXOS_20_Printer_Driver_Specificaton.pdf) (1984-Nov-29)
- [EXOS version 2.1](http://enterprise.iko.hu/technical/ET16-3_EXOS_21_Printer_Driver_Specificaton.pdf) (1985-Jan-16) *(current)*
