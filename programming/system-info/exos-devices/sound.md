# SOUND:

`SOUND:`

Драйвер звукового пристрою надає високорівневий інтерфейс до чипа [DAVE](../../../hardware/hm-dave.md), що дозволяє користувачеві використовувати більшість можливостей цього чипа.

Він дозволяє відкривати лише один [канал EXOS](../info_channels.md) одночасно. Звуковий чип має чотири джерела звуку — три тональні канали та один канал шуму. Звуковий драйвер підтримує чергу звуків для кожного з цих звукових каналів. Кожен звук у черзі відтворюється по черзі після завершення попереднього. Ці звукові черги мають фіксований максимальний розмір у 25 звуків у кожній черзі та зберігаються в ОЗП виділеному для каналу.

Окрім звукових черг, звуковий пристрій підтримує список огинаючих (огинаючих ліній / envelopes), кожна з яких має номер від 0 до 254. Кожен звук у чергах посилається на конкретну огинаючу або на «порожню» огинаючу (номер 255). Під час безпосереднього відтворення звуку вказана огинаюча керує зміною висоти тону, а також лівої та правої амплітуди протягом всієї його тривалості. Область збереження для огинаючих знаходиться в ОЗП каналу, а її розмір має бути вказаний за допомогою [змінної EXOS](../exos-variables/exos_var15.md) перед відкриттям каналу.
