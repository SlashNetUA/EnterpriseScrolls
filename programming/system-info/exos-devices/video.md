# VIDEO:

`VIDEO:`

Відеодрайвер керує відображенням будь-якої кількості відеосторінок у різноманітних відеорежимах, використовуючи більшість можливостей чипа NICK.

Відображення організовано у вигляді відеосторінок, де одна сторінка відповідає одному [каналу EXOS](../info_channels.md), відкритому для відеодрайвера. Перед відкриттям каналу у відеодрайвері користувач повинен задати різні параметри, такі як відеорежим та розмір сторінки, шляхом встановлення [змінних EXOS](../info_exos-variables.md). Після цього канал можна відкрити для пристрою `VIDEO:`. Якщо вказано ім'я файла або номер пристрою, вони ігноруються. Відеодрайвер самостійно вирахує, скільки RAM йому потрібно для цієї відеосторінки, і отримає цю кількість оперативної пам'яті від EXOS, включаючи обсяг для всіх необхідних змінних. Єдине обмеження на кількість відеосторінок — це обсяг доступної пам'яті. Відеосторінки можуть використовувати лише внутрішні 64 Кб відеопам'яті.

Після того, як канал налаштовано таким чином, користувач може зчитувати символи з відеосторінки або записувати їх туди. Зчитані або записані дані матимуть різне значення для різних режимів, особливо керуючі символи та escape-послідовності.

На цьому етапі відеосторінка ще не буде видима на екрані. Для того, щоб відеосторінка дійсно відобразилася на екрані, потрібен виклик спеціальної функції. Лише в цей момент налаштовуються відповідні блоки параметрів рядків, після чого з'являється текст або графіка. Можна відобразити будь-яку вертикальну секцію відеосторінки у будь-якому вертикальному положенні на екрані, перекриваючи все, що відображалося на цих скануючих рядках раніше. Якщо ширина сторінки менша за повну ширину екрана, поля будуть скориговані так, щоб відобразити сторінку по центру екрана.

Текстові сторінки забезпечують відображення символів з 128-символьного шрифту, який ініціалізується стандартним набором символів ASCII, але будь-які символи можуть бути перевизначені користувачем. Також текстові сторінки надають різні функції керування, включаючи позиціонування курсора, прокручування будь-якої секції сторінки та автоматичне прокручування.

Існує безліч різних графічних режимів, що надають вибір роздільної здатності, кількості кольорів та використання пам'яті. Усі графічні режими підтримують малювання ліній та еліпсів у різноманітних режимах малювання та стилях ліній (пунктирні лінії тощо). Символи можуть відображатися за допомогою того ж шрифту, що й на текстових сторінках. Існує складний алгоритм суцільної заливки, який заповнює будь-які довільні форми з урахуванням обмежень стека.
