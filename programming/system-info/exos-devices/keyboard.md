# KEYBOARD:

`KEYBOARD:`

Драйвер клавіатури дозволяє відкривати лише один канал одночасно. Канал можна відкрити, вказавши назву пристрою `KEYBOARD:`, при цьому будь-яке ім'я файла чи номер пристрою ігноруються. Якщо канал для драйвера клавіатури вже відкритий, буде повернено помилку ([.2NDCH](../errors/err-2ndch.md)). Перед відкриттям каналу немає потреби налаштовувати змінні EXOS.

Пристрій клавіатури має процедуру обробки переривань, яка сканує матрицю клавіатури кожного відеокадру (50 разів на секунду). Вона виявляє натискання клавіш, перетворює їх у коди ASCII та буферизує один символ.

Підтримує програмування восьми функціональних клавіш. Кожна з них може бути запрограмована окремо для використання з клавішею Shift та без неї, що фактично дає 16 функціональних клавіш. Якщо рядок, запрограмований для будь-якої з цих функціональних клавіш, має нульову довжину, то замість повернення символів натискання цієї функціональної клавіші викликає програмне переривання. Ці  функціональні клавіші також повертають [певний код](../info_characters.md) при одночасному натисканні з клавішами **Ctrl** або **Alt**, що фактично дає ще 16 функцій.

Драйвер клавіатури обробляє вбудований джойстик так, ніби це чотири клавіші керування курсором, і забезпечує діагональний рух шляхом чергування двох кодів курсора. Автоповтор підтримується для всіх клавіш. Як затримку до початку автоповтору, так і швидкість автоповтору можна змінювати.

Клавіатура забезпечує звуковий відгук, запускаючи звуковий пристрій для відтворення клацання при кожному натисканні клавіші. Цю функцію користувач може вимкнути.
