# DISK:

`DISK:`  
`DISKn:`  
`DISK-n:`  
`n:`  
`d:`

Disk drives.

**n**: disk number (**1**-**26**).  
**d**: disk letter (**A**-**Z**).

Драйвер дискового пристрою підключається до EXOS як «користувацький» пристрій (user device) під час запуску EXDOS.

Хоча дисковий пристрій описується як єдиний пристрій, насправді для нього підключається кілька дескрипторів пристроїв. Існує один дескриптор пристрою з назвою `DISK:`, який налаштовано як пристрій за замовчуванням в EXOS. Коли використовується цей пристрій, номер юніта (номер пристрою/дисковода) вказує, який саме дисковод потрібен.

Крім того, підключається окремий дескриптор пристрою для кожного підтримуваного дисковода з назвами пристроїв `A:`, `B:`, .... `Z:`. Коли використовуються ці пристрої, переданий користувачем номер юніта ігнорується, а ім'я пристрою визначає дисковод. Це дозволяє користувачеві посилатися на дисководи літерами, а не номерами, для сумісності з іншими операційними системами (наприклад, CP/M, MSX-DOS та MS-DOS).
