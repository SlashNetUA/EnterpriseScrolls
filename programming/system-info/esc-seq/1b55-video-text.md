# Прокрутити екран догори

Тип каналів: текстові відеосторінки

Формат: 

`escU`

hex: `1B`,`55`

dec: `27`,`85`

(Windows)  
`<ESC>U<m><n>` — Прокручування вгору від рядка **m−32** до рядка **n−32**; **m ≤ n**.

Див. також [прокрутити екран донизу](1b44-video-text.md).
