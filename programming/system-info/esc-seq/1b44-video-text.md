# Прокрутити екран донизу

Тип каналів: текстові відеосторінки

Формат: 

`escD`

hex: `1B`,`44`

dec: `27`,`68`

(Windows)  
`<ESC>D<m><n>` — Прокручування вниз (scroll down) від рядка **m−32** до рядка **n−32**; **m ≤ n**.

Див. також [прокрутити екран догори](1b55-video-text.md).
