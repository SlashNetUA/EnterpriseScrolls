# MICROTEAM

Засновники: [Міклош Банко](../peoples/hu/pers_miklos-banko.md) та

Угорська компанія що спеціалізувалась на виробництві апаратних розширень для платформ ZX Spectrum, Sinclair QL, та Enterprise (згодом перейшовши на випуск продукції для ПК-сумісних комп'ютерів).

Серед їхніх розробок можна виділити такі:

 - карта EXDOS із розширенням ОЗП
 - плати картриджів для встановлення ПЗП
 - інтерфейс підключення периферії від Commodore (таких як дисководи та принтери), реалізований у форматі картриджа
 - програматор EPROM

Крім того, ця компанія розробила багатофункціональний файловий менеджер PiCi Tools (за образом і подобою PC Tools для ПК-сумісних комп'ютерів).
