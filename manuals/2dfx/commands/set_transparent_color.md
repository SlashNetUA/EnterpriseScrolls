### SET_TRANSPARENT_COLOR (40h..4Fh / 64..79)

Ця команда дозволяє задавати індекс кольору, який 2dfx надалі вважатиме прозорим. Якщо спрайт або інша графічна команда з перевіркою прозорості містить піксель такого кольору, 2dfx не відмальовує його, а вказує комп'ютеру неактивним станом сигналу **/EXTC**, що на цьому місці має виводитись графічні дані згенеровані Nick (що виводяться без карти 2dfx). У спрайтах перевірка зіткнень також відбувається лише між видимими (тобто непрозорими) пікселями. Останні чотири біти коду команди вже самі по собі визначають індекс прозорого кольору, тому передавати додаткові параметри для цієї команди не потрібно.

> У команди немає параметра для порту [F9h (249)](../../../programming/system-info/ports/port249.md).

Початкове значення після ввімкнення — нульовий індекс кольору (**0**).
