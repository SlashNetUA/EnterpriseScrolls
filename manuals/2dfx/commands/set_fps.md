## SET_FPS (51h / 81)

Встановлює частоту оновлення сцен 2dfx. Початкове значення дорівнює **0**, що відповідає роботі на **50 fps**: 2dfx формує новий кадр при кожному вертикальному синхроімпульсі, тобто на рендеринг відводиться **20 мс**. Якщо програма, гра або демка не потребує такого швидкого оновлення, або графічне завдання занадто складне для 20-мілісекундного ліміту, значенням **1** команди **SET_FPS** можна переключитися на **25 fps**. У цьому випадку один рендеринг може тривати до **40 мс**, а готове зображення залишається видимим протягом двох 50-герцових відеокадрів.

| **Назва параметра** | **7** | **6** | **5** | **4** | **3** | **2** | **1** | **0** | **Опис**                              |
| ------------------- |:-----:|:-----:|:-----:|:-----:|:-----:|:-----:|:-----:|:-----:| ------------------------------------- |
| **режим роботи**    |   0   |   0   |   0   |   0   |   0   |   0   |   0   |   a   | слугує для налаштування режиму роботи |

- **a:**
    - **0** = 50 fps
    - **1** = 25 fps
- **0** — обов'язково має бути встановлено в нуль.
