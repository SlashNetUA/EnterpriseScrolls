## Регістр статусу

Зчитування порту [F8h (248)](../../programming/system-info/ports/port248.md) повертає значення регістра статусу [2dfx](../../hardware/hv-2dfx.md). Активний стан кожного сигналу позначається значенням **0**! Біти регістра мають наступне значення:

| **Біт**   | **Назва**          | **Опис**                                                                                                                                                                                                                                                                                                                                        |
| --------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **bit 7** | COLLISION_DETECTED | У попередньому кадрі принаймні два активних спрайти мали видимі пікселі, що перекривалися. Перевірка зіткнень здійснюється з точністю два пікселі по горизонталі та один піксель по вертикалі.                                                                                                                                                  |
| **bit 6** | 2DFX_PRESENT       | Після завершення ініціалізації 2dfx жорстко утримує цей біт у значенні **0**. Завдяки цьому користувацька програма може перевірити наявність карти 2dfx у системі (див. також розділ «Ініціалізація»).                                                                                                                                          |
| **bit 5** | RENDER_OVERRUN     | Активний, якщо 2dfx не зміг виконати задане завдання рендерингу у відведений для кадру час. Очищається командою [CLEAR_RENDER_OVERRUN](commands/clear_render_overrun.md).                                                                                                                                                                                                       |
| **bit 4** | RASTER_INT4        | Спрацювало четверте растрове переривання.                                                                                                                                                                                                                                                                                                       |
| **bit 3** | RASTER_INT3        | Спрацювало третє растрове переривання.                                                                                                                                                                                                                                                                                                          |
| **bit 2** | RASTER_INT2        | Спрацювало друге растрове переривання.                                                                                                                                                                                                                                                                                                          |
| **bit 1** | RASTER_INT1        | Спрацювало перше растрове переривання.                                                                                                                                                                                                                                                                                                          |
| **bit 0** | RENDER_TIME        | Слугує для осцилографічного вимірювання часу рендерингу. На платі 2dfx цей сигнал також виведено на контактний майданчик для пайки з позначкою **RTIME**. Активний, поки рендерер обчислює дані кадру. Після виконання команди [SYS_RESET](commands/sys_reset.md) його значення залишається рівним **0** протягом виконання команди, після чого змінюється на **1**. |

Крім того, стан бітів регістра статусу виводиться на вісім зелених світлодіодів та таку ж кількість контактних майданчиків для пайки розташованих на друкованій платі 2dfx, що полегшує проведення вимірювань за допомогою аналізатора або осцилографа.

Детальну інформацію про біти статусу можна знайти в описі відповідних команд або подій.
