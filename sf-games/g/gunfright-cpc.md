## Опис

**Gunfright** - це гра, випущена в 1986 році компанією Ultimate для платформи Amstrad CPC. Гравець потрапляє в світ Дикого Заходу, де йому потрібно змагатися з ворогами в стрілянині. Гра має яскраву графіку та просте управління, що робить її доступною для гравців усіх рівнів.

**Правила гри:**
1. **Меню:** Для навігації між пунктами меню використовуйте клавіші F1, F2, F3.
2. **Управління:**
   - Клавіатура (O, P, Q, A, SPACE)
   - Вбудований джойстик + ENTER
   - Зовнішні джойстики (EXT1/EXT2)
3. **Пауза:** натисніть ESC.
4. **Зміна палітри:** натискайте F8, щоб змінити кольори гри:
   - F1-F4 - змінюють кольори 0-3.
   - INT JOY - переміщення по палітрі.
   - ENTER - повернення до оригінальних кольорів.
   - F7 - повернення до гри.
5. **Додаткові можливості:** Після завантаження ви можете вибрати безсмертя та безкінечні гроші.
